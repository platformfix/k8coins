# Supply chain security

## Provenance and signing

Every image push gets a signed build provenance attestation, generated by
GitHub's own Sigstore-backed [artifact attestations](https://docs.github.com/en/actions/security-guides/using-artifact-attestations-to-establish-provenance-for-builds),
not a manually maintained signature. Verify any image:

```bash
gh attestation verify oci://ghcr.io/platformfix/k8coins-rng:latest --repo platformfix/k8coins
```

The published Helm chart gets the same treatment - every chart release's
`.tgz` is attested too, not just the images:

```bash
gh release download k8coins-<version> --repo platformfix/k8coins --pattern "*.tgz"
gh attestation verify k8coins-<version>.tgz --repo platformfix/k8coins
```

## Software bill of materials

An SPDX SBOM is generated and attested the same way for each image, pinned
to the exact digest pushed rather than a floating tag:

```bash
gh attestation verify oci://ghcr.io/platformfix/k8coins-rng:latest \
  --repo platformfix/k8coins --predicate-type https://spdx.dev/Document
```
